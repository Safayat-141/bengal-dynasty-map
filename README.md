# বাংলার শাসন ইতিহাস — ইন্টারঅ্যাকটিভ ম্যাপ (রিয়েল ওয়ার্ল্ড ম্যাপ)

প্রাচীন যুগ থেকে ইংরেজ শাসনের সূচনা পর্যন্ত বাংলার ১১টি রাজবংশ/শাসনব্যবস্থার
ইন্টারঅ্যাকটিভ টেরিটরি ম্যাপ। এবার **প্রকৃত বিশ্ব মানচিত্রের** উপর ঐতিহাসিক
অঞ্চলগুলো দেখানো হয়েছে।

## ✨ ফিচার
- **Leaflet.js** ভিত্তিক রিয়েল ওয়ার্ল্ড ম্যাপ
- বিশ্বের দেশগুলোর প্রকৃত সীমানা (Natural Earth / world.geo.json)
- ৯টি ঐতিহাসিক অঞ্চল (মগধ, কামরূপ, পুণ্ড্রবর্ধন, গৌড়, রাঢ়, বঙ্গ, সমতট, তাম্রলিপ্তি, উৎকল) — আধুনিক ভূগোলের উপর আনুমানিক পলিগন
- ক্লিকযোগ্য টাইমলাইন — ১১টি রাজবংশ
- প্রতিটি অঞ্চলে হোভার করলে টুলটিপ
- প্রতিটি রাজবংশের আর্থসামাজিক অবস্থা, সফলতা, ব্যর্থতা, উত্থান ও পতন
- ১০০+ শাসকের নাম ও রাজত্বকাল
- সম্পূর্ণ রেসপন্সিভ
