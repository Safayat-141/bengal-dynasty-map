# বাংলার শাসন ইতিহাস — ইন্টারঅ্যাকটিভ ম্যাপ

প্রাচীন যুগ থেকে ইংরেজ শাসনের সূচনা পর্যন্ত বাংলার ১১টি রাজবংশ/শাসনব্যবস্থার
ইন্টারঅ্যাকটিভ টেরিটরি ম্যাপ। প্রতিটি রাজবংশের শাসনাঞ্চল, রাজধানী, সময়কাল,
আর্থসামাজিক অবস্থা এবং **সকল শাসকের পূর্ণ তালিকা** রয়েছে।

## ✨ ফিচার
- ক্লিকযোগ্য টাইমলাইন — ১১টি রাজবংশ
- SVG টেরিটরি ম্যাপ — ৯টি অঞ্চল (মগধ, কামরূপ, পুণ্ড্রবর্ধন, গৌড়, রাঢ়, বঙ্গ, সমতট, তাম্রলিপ্তি, উৎকল)
- প্রতিটি অঞ্চলে হোভার করলে দেখা যায় কোন কোন রাজবংশ সেখানে শাসন করেছে
- প্রতিটি রাজবংশের আর্থসামাজিক অবস্থা, সফলতা, ব্যর্থতা, উত্থান ও পতনের বিবরণ
- ১০০+ শাসকের নাম ও রাজত্বকালের তালিকা
- সম্পূর্ণ রেসপন্সিভ — মোবাইল ও ডেস্কটপে কাজ করে
- কোনো বিল্ড স্টেপ বা ডিপেন্ডেন্সি নেই — pure static HTML/CSS/JS
